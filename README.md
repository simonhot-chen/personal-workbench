# 个人办公工作台（演示版）

一个单文件 HTML 的个人办公工作台，天空之城主题。这是**脱敏后的演示版**，不含任何真实数据。

## 这是什么

一个把「今日焦点 / 今天待办 / 日历 / 灵感速记 / 项目跟进 / OKR 对齐 / 每周复盘 / 数据说明」八个模块整合在一起的个人工作台，单文件、零外部依赖、响应式适配 PC 和手机。

## 数据说明

- 本演示版已脱敏，`databaseId`、飞书标识符、页面节点 id 全部替换为占位符
- 数据原本通过 WorkBuddy 资料库的云端数据表 + 飞书任务系统同步，演示版**不连接任何真实数据**
- 打开后是干净的空白界面（数据是从云端拉取的，脱敏后连不上）

## 如何改成你自己的

1. 把代码里的 `YOUR_TASK_DATABASE_ID`、`YOUR_PROJECT_DATABASE_ID`、`YOUR_OKR_DATABASE_ID`、`YOUR_NOTE_DATABASE_ID`、`YOUR_META_DATABASE_ID` 替换成你自己的数据库 id
2. 在支持 `window.__SMART_PAGE__.database` 的环境（WorkBuddy 资料库）中运行
3. 接入你自己的飞书任务系统

**不想碰代码？** 跟着《工作台搭建指导.md》从零搭一套属于你自己的 OKR 工作台——先想清楚目标，再拆关键结果，最后落到任务，全程不用懂技术。

## 功能

- **今日焦点**：每天打开先看这里，逾期标红、昨天没做完自动滚到今天，卡住的项目置顶
- **今天待办**：优先级 P1~P4、关联项目、按项目筛选、搜索、单条/全部顺延
- **日历**：周一起始月历，逾期日期标红，点一天看当天的清单
- **灵感速记**：随手记，打标签，按标签翻
- **项目跟进**：项目名 / 当前阶段 / 下一步 / 卡点，卡住自动进「今日焦点」；任务挂到项目下自动算进度
- **OKR 对齐**：大目标（O）→ 关键结果（KR）→ 关联项目 → 待办，串成一条线；KR 进度 = 关联项目任务完成率（或手动进度）
- **每周复盘**：完成任务数 / 新增数 / 灵感数 / 逾期数 / 卡住项目数，按优先级分布、精力归集、卡点汇总
- **数据说明**：导出 / 导入 JSON 备份，清空示例 / 清空全部

## 技术特点

- 单文件 HTML，CSS/JS/图标全部内联，零外部依赖
- 图表用内联 SVG 手写
- 天空之城主题 + CSS 动画动图 + Web Audio 合成氛围音乐
- 响应式：PC 侧边栏导航，手机汉堡抽屉
